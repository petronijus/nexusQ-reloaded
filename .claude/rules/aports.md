# Aports (pmos/)

- A change to anything an aport packs bumps its `pkgrel`, and the CHANGELOG
  names the new revision. Without it the OTA repo never offers the change.
- A new file: in `source=`, staged by `docker-build.sh` (Phase 6/7) when it
  lives outside the aport, installed in `package()`. `tests/test_aports.py`
  catches a file left out of `source=` and a kernel patch that is not applied.
- `sha512sums` are regenerated by the build (`pmbootstrap checksum`); do not
  hand-edit them.
- Enable a systemd unit with a preset (`NN-nexusq-*.preset`), never a bare
  symlink. A `Type=oneshot` with `WantedBy=X.target` holds X. No `After=` on
  our own services unless you have checked for an ordering cycle.
- A `.post-install` that patches another package's file runs before that
  package is unpacked: use an apk trigger.
- `.post-upgrade` runs on units that took an older image: handle every earlier
  state, and test it in a container (`# needs: docker` suites under `tests/`).
- `userspace/nq-healthd/nq-healthd.c` is the tested copy of
  `pmos/device-google-steelhead/nq-healthd.c`: edit the former, copy it over.
