nexusQ-reloaded

Signed apk OTA repository — mainline Linux & postmarketOS on the Google Nexus Q (steelhead).

Over-the-air updates for the device software: the on-device daemons (nexusqd, nexusq-control, nexusq-btagent, nexusq-setupd, nexusq-mqtt), the device configuration package, the A/B rootfs & kernel-OTA tooling, and the kernel apk that nq-kernel-ota uses as its boot-image payload. All packages are signed — the device already trusts the build key in /etc/apk/keys.

Use on the device

# one-time: add the repository
echo https://petronijus.github.io/nexusQ-reloaded/nexusq >> /etc/apk/repositories

# update (or use the companion app's "Nexus Q" update button)
apk update && apk upgrade --ignore linux-google-steelhead

Kernel updates are not applied by apk — the kernel apk here is fetched by nq-kernel-ota, written to the trial boot slot, and promoted only after the device boots healthy.
